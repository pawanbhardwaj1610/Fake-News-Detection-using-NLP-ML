# Real-Time Fake News Detection System

## Features
- Fake vs Real prediction
- Credibility score
- Web scraping
- Flask API
- Modern Streamlit UI

## Steps

1. Prepare dataset
python ml/prepare_dataset.py

2. Train model
python ml/train_model.py

3. Run API
python api/app.py

4. Run dashboard
streamlit run dashboard/dashboard.py
